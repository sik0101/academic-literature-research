# APA 7th Edition Quick Reference Guide

A quick reference for formatting academic citations and references in APA 7th edition style.

---

## Citation Basics

### In-Text Citations

**Single Author:**
```
(Smith, 2020)
Smith (2020) argues that...
```

**Multiple Authors (2 authors):**
```
(Smith & Jones, 2020)
Smith and Jones (2020) found...
```

**Multiple Authors (3+ authors):**
```
First citation: (Smith, Jones, & Brown, 2020)
Subsequent citations: (Smith et al., 2020)
```

**No Author (use organization or title):**
```
(American Psychological Association, 2020)
("Title of Work," 2020)
```

**Direct Quote:**
```
"Quote text" (Author, Year, p. XX)
Author (Year) stated, "Quote text" (p. XX).
```

## Reference List Format

### Journal Article

```
Author, A. A., & Author, B. B. (Year). Title of article. 
Title of Journal, Volume(Issue), page range. 
https://doi.org/xx.xxxx/xxxxx
```

**Example:**
```
Smith, J., & Jones, M. (2020). Deep learning for natural language processing. 
Journal of Machine Learning, 45(3), 234-256. 
https://doi.org/10.1234/jml.2020.45.3.234
```

### Conference Paper

```
Author, A. A., & Author, B. B. (Year). Title of paper. 
In Proceedings of Conference Name (pp. page range). 
Publisher. https://doi.org/xx.xxxx/xxxxx
```

**Example:**
```
Brown, K., & Lee, S. (2021). Transformer architectures for sequence modeling. 
In Proceedings of the 2021 International Conference on Machine Learning (pp. 1234-1245). 
ACM. https://doi.org/10.1145/3456789.3456790
```

### Book

```
Author, A. A. (Year). Title of book. Publisher.
```

**Example:**
```
Goodfellow, I., Bengio, Y., & Courville, A. (2016). Deep learning. 
MIT Press.
```

### Book Chapter

```
Author, A. A., & Author, B. B. (Year). Title of chapter. 
In C. D. Editor (Ed.), Title of book (pp. page range). Publisher.
```

**Example:**
```
LeCun, Y., & Hinton, G. (2015). Deep learning. 
In Y. LeCun & Y. Bengio (Eds.), Neural networks and deep learning (pp. 1-50). 
MIT Press.
```

### Preprint (arXiv)

```
Author, A. A., & Author, B. B. (Year). Title of paper. 
arXiv preprint arXiv:XXXX.XXXXX.
```

**Example:**
```
Vaswani, A., Shazeer, N., Parmar, N., et al. (2017). Attention is all you need. 
arXiv preprint arXiv:1706.03762.
```

### Website/Online Source

```
Author, A. A. (Year). Title of page. Retrieved from https://www.example.com
```

**Example:**
```
OpenAI. (2023). GPT-4 technical report. Retrieved from https://openai.com/research/gpt-4
```

## Reference List Organization

1. **Alphabetical order** by first author's last name
2. **Chronological order** if same author (oldest first)
3. **Hanging indent** for each entry (first line flush left, subsequent lines indented)

---

## Common Formatting Rules

### Capitalization

**Titles (Sentence case):**
- Only first word and proper nouns capitalized
- Example: "Deep learning for natural language processing"

**Journal Names (Title Case):**
- Major words capitalized
- Example: "Journal of Machine Learning Research"

### Punctuation

- Period after author names
- Period after year
- Period after article title
- Comma between volume and issue
- Colon before page numbers
- Period at end of reference

### DOI Format

- Preferred: `https://doi.org/10.1234/example`
- Alternative: `doi:10.1234/example`
- Always include if available

## Quick Checklist

- [ ] All authors listed (or et al. for 3+)
- [ ] Year in parentheses
- [ ] Article title in sentence case
- [ ] Journal title in title case
- [ ] Volume number in italics
- [ ] Issue number in parentheses (if available)
- [ ] Page numbers included
- [ ] DOI included (if available)
- [ ] References in alphabetical order
- [ ] Hanging indent applied

---

## Common Mistakes to Avoid

| Mistake | Correct |
|---------|---------|
| All authors capitalized | Only first word and proper nouns |
| Missing DOI | Include DOI when available |
| Journal title not italicized | Italicize journal title |
| No hanging indent | Apply hanging indent |
| Inconsistent punctuation | Follow format consistently |
| Missing page numbers | Include page range |
